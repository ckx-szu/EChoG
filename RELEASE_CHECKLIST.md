# Release checklist

- [x] Keep the source repository private during preparation.
- [ ] Review patient privacy separately from author anonymity.
- [ ] Inspect image/video pixels, file metadata, filenames, and record identifiers.
- [ ] Do not publish identity mappings, clinical source spreadsheets, local paths, or credentials.
- [ ] Audit code and dependencies before uploading; retain required third-party notices.
- [ ] Confirm reference-frame annotation provenance and disease-label semantics.
- [ ] Document differences between the entire cohort and benchmark-eligible subsets.
- [ ] Confirm patient-group separation and fixed evaluation samples.
- [ ] Specify data access, code licensing, and data terms accurately.
- [ ] Verify examples and evaluation commands in a clean environment.
- [ ] Remove author/institution identifiers from review materials without removing required third-party attribution.
- [ ] Review binary documents and external links; anonymous mirrors do not automatically sanitize clinical media.
- [ ] Set anonymous-link expiry beyond the review period and test logged-out access.
- [ ] Freeze and record the submitted artifact version.
- [ ] Replace paper URL placeholders only after verifying the actual link.
